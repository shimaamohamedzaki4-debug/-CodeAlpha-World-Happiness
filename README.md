# World Happiness - Data Visualization

## Project Overview

This project is part of the CodeAlpha Data Analytics Internship.

The project focuses on visualizing the World Happiness dataset to identify patterns, relationships, and differences in happiness scores across countries.

## Objectives

* Explore the World Happiness dataset.
* Understand the structure of the data.
* Create meaningful data visualizations.
* Identify patterns and relationships between happiness and different factors.
* Communicate insights clearly using charts and graphs.

## Dataset

The dataset contains information about **156 countries** and **9 columns**.

The main variables include:

* Overall Rank
* Country or Region
* Happiness Score
* GDP per Capita
* Social Support
* Healthy Life Expectancy
* Freedom to Make Life Choices
* Generosity
* Perceptions of Corruption

## Tools and Libraries

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab

## Data Overview

The dataset was explored by checking:

* Number of rows and columns
* Data types
* Missing values
* Duplicate values

The dataset contains **156 rows and 9 columns**, and no duplicate rows were found.

## Visualizations

The project includes the following visualizations:

### 1. Top 10 Happiest Countries

A bar chart was created to compare the Happiness Scores of the top 10 countries.

### 2. Happiness Score vs GDP per Capita

A scatter plot was used to explore the relationship between Happiness Score and GDP per Capita.

### 3. Happiness Score vs Healthy Life Expectancy

A scatter plot was created to examine the relationship between Happiness Score and Healthy Life Expectancy.

### 4. Correlation Heatmap

A correlation heatmap was created to understand relationships between the numerical variables.

### 5. Top 10 Countries by Social Support

A bar chart was created to show the countries with the highest Social Support values.

## Key Insights

* Finland had the highest Happiness Score with **7.769**.
* South Sudan had the lowest Happiness Score with **2.853**.
* The top 10 happiest countries had relatively high Happiness Scores.
* Happiness Score showed a positive relationship with GDP per Capita.
* Happiness Score also showed a positive relationship with Healthy Life Expectancy.
* The visualizations helped identify patterns and relationships between different factors.

## Conclusion

The analysis shows differences in Happiness Scores across countries.

The visualizations demonstrated how factors such as GDP per Capita and Healthy Life Expectancy are related to Happiness Score.

This project helped me practice data visualization using Python and learn how to communicate data-driven insights clearly.
